# Harmónia by Gabi – coaching landing oldal

Önálló, mobilra is igazodó statikus honlap. Nem igényel telepítést vagy buildelést.

## Tartalom
- index.html – a teljes oldal, a stílusokkal és a két ügyfélvisszajelzéssel
- assets/ – a honlapon használt két fénykép
- .nojekyll – közvetlen statikus kiszolgálás GitHub Pages alatt

## Feltöltés GitHub Pages-re
1. Csomagold ki ezt a ZIP-fájlt.
2. Hozz létre egy új GitHub repositoryt.
3. A kicsomagolt index.html fájlt és az assets mappát töltsd a repository gyökerébe. A README.md és .nojekyll fájl is feltölthető. Ne a ZIP-fájlt töltsd fel, és ne legyen még egy külső mappa az index.html körül.
4. A repository Settings → Pages menüjében válaszd a Deploy from a branch lehetőséget.
5. Branch: main; mappa: / (root). Kattints a Save gombra.
6. A közzététel elkészülte után a Pages felület mutatja a weboldal címét.

A telefonos gomb hívást, az e-mailes gomb levélírást indít a látogató saját alkalmazásában. Nincs szerver vagy adatbázis, és nem kell ChatGPT-bejelentkezés. Az összes képhivatkozás relatív, ezért repository alatti GitHub Pages-címen is működik.

A szöveg és a kinézet az index.html fájlban szerkeszthető. A képek az assets mappában találhatók.

Nyilvános használat előtt kérd az idézett ügyfelek hozzájárulását a visszajelzésük megjelenítéséhez.
